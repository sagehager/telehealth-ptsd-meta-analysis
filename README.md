# Telehealth vs. In-Person Psychotherapy for PTSD: A Meta-Analysis

Random-effects meta-analysis of 8 RCTs (N = 812) comparing synchronous video telehealth with in-person delivery of the same psychotherapy for adults with PTSD. Completed for EPID 5015 at Georgetown University, Fall 2025.

**Methods:** Pooled standardized mean difference (Hedges' g) with the `meta` package, I² heterogeneity, meta-regression on publication year, and Egger's test for publication bias.

**Result:** No significant difference between telehealth and in-person treatment (SMD 0.05, 95% CI −0.17 to 0.27).
